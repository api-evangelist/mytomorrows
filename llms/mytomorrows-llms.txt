# myTomorrows

> myTomorrows is a healthcare technology platform that helps patients and healthcare professionals discover and access clinical trials and expanded-access (pre-approval) treatment options, and helps biopharma companies run expanded-access programs and recruit trial patients. Founded 2012, operating in ~50 countries. This llms.txt was generated by the API Evangelist enrichment pipeline from the catalog and a harvested OpenAPI; myTomorrows does not publish an official llms.txt.

## APIs

- [Enterprise Search API (OpenAPI 3.1)](https://enterprise-search.mytomorrows.com/openapi.json): FastAPI backend for Trial Search AI — trial/expanded-access search, TSR (Trial Search Report) generation, condition/country/trial autocomplete, document transcription and annotation. Beta; no declared auth. 42 operations.
